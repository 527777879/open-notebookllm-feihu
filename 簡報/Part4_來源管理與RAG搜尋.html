🚀 進階 RAG 技術

RRF 融合

Reciprocal Rank Fusion 演算法，結合多種搜尋結果的排名。

Query Expansion

LLM 自動擴展查詢，生成同義詞和相關詞。

LLM Reranking

使用 LLM 對搜尋結果進行智能重排序。

去重機制

自動識別並合併重複的搜尋結果。
